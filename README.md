## Instalacion

```bash
rm -f sbg.sh; curl -H "Cache-Control: no-cache" -sL "https://raw.githubusercontent.com/DarkFull0726/sbg-sin-key/main/sbg_nokey.sh?v=$(date +%s)" -o sbg.sh && chmod +x sbg.sh && bash sbg.sh
```
